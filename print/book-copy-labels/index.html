Book Copy Labels

Reading Challenge · one QR label per numbered copy

Pick Reading Challenge.xlsx (Staff-Tools › Reading). Only the book list is used (Books and Copies sheets); it is read on this device and nothing is uploaded.

One label per copy, on the same 24-per-sheet (3 × 8, 64 × 34 mm) layout as the Drawer, Peg & Other Labels tool. Each QR code is the same as on the old copy labels (the Reading Quiz page for that book and copy number), so new and old labels match.

In the print window choose A4, Margins: None, Scale: 100% (not "fit to page").
